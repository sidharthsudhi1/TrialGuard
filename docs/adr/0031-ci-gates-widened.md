# AD-31 — The CI gate is widened until it can fail

> Part of the TrialGuard architectural decision log ([index](../../README.md#architectural-decision-log)). Amendments are appended here rather than replacing what they correct.

## Decision

The CI gate is widened until it can fail, and every rule that stays off is a recorded decision rather than a default. `ruff` ran `E,F,I`, `mypy` covered three hand-picked files of ~10k lines, `pip-audit` carried `continue-on-error: true`, and there was no coverage gate or lockfile -- a configuration that passes whatever it is handed. Widened to `E,F,I,B,ASYNC,S,UP,SIM,RUF,PTH`, mypy over **all 65 source files** (clean), coverage gated at 55 under a measured **59.24%**, and a blocking audit. It caught five things that were not style: `assert` used as a production state guard in `file_index.py`, which `python -O` deletes and which then returns uninitialised state; a silent-truncation class in 21 `zip` calls, where ruff's own autofix writes `strict=False` and preserves the defect, so `strict=True` went in instead and exposed **a test whose mock violated the contract it was testing** -- `embed_batch` as a bare `MagicMock` returns one object rather than one vector per input, so `refresh()` zipped mismatched lengths and the test passed regardless; an annotation that disagreed with its own body (`ndcg_at_k` declared `dict[str, int]` while being handed label names); and one `spent` variable holding tokens on one line and dollars twelve lines later inside a single function. **Dependency CVEs were fixed rather than accepted**: aiohttp 3.14.1 to 3.14.3 and anyio 4.14.0 to 4.15.1, both in the served request path, plus torch 2.12.1 to 2.14.0, with floors in `pyproject.toml` so a fresh resolve cannot walk back. `pip` and `setuptools` are skipped by id because they are the runner's toolchain, not anything this project ships, and failing every build for something no commit can fix trains people to ignore the gate. Coverage's total is the least interesting number in it -- `verify/grounding.py` is at **100%**, the agent graph 97%, and the uncovered 41% is eval harnesses and one-shot scripts. [`e5_findings.md`](../../data/reports/e5_findings.md)

## Alternatives considered

`--strict` mypy (demands annotations throughout research code for little return, and the honest description of this configuration is a floor); accepting the CVEs with an advisory gate, which is what `continue-on-error` had already made of it; taking ruff's `strict=False` autofix for B905, which silences the rule while keeping the truncation it warns about; enabling `RUF100`, which reads per-file-ignored rules as not-enabled, strips the `noqa` suppressing them, and reintroduced two errors when run
