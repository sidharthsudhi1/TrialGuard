# AD-26 — The oncology scope lock becomes a parameter

> Part of the TrialGuard architectural decision log ([index](../../README.md#architectural-decision-log)). Amendments are appended here rather than replacing what they correct.

## Decision

The oncology scope lock is now a parameter rather than a constant, and what it was hiding is measured. `fetch_oncology_trials` hardcoded its condition query, so every recall figure in this repo was measured on a haystack pre-narrowed to the right specialty -- a property of the eval, not of the retriever. Widening it is a deliberate reversal of a CLAUDE.md lock, so the default is unchanged and the caller opts in. Measured by holding TREC 2021 gold fixed and growing the corpus with 99,098 real all-conditions recruiting trials ([`e1c_findings.md`](../../data/reports/e1c_findings.md)): at **4.79x dilution recall@100 falls 0.1759 -> 0.1102**, retaining 62.6% where chance dilution would retain 20.9%, so the embedder is **3.0x better than chance** and the same retention holds at k=50, 100 and 200 rather than being a cut-off artifact. The number is dense-only on raw-note queries and is **not a system number** -- production runs keyword extraction, a lexical arm and RRF and scores 0.440 on this cohort -- because mixing them in would confound whether the embedder still separates with whether FTS still separates. The consequence that binds: the all-conditions corpus is 125,247 trials and [AD-25](0025-matrix-hnsw-crossover.md) puts the matrix crossover near 50k, so **widening the scope and keeping the in-process matrix are not independent decisions**. **Amended 2026-09-23: the CLAUDE.md lock is now formally lifted** rather than worked around. As first written this entry claimed a reversal while the governing document still asserted the lock, which is the drift this log exists to prevent; the code change alone had left the default untouched and widened nothing in production, and that remains true -- what changed is that scope is now a call-site decision carrying a stated index consequence, instead of a prohibition contradicted by its own decision log

## Alternatives considered

Ingesting all conditions and reporting the new corpus size, which measures nothing about retrieval; measuring with keywords and RRF on (a better system number and a worse experiment, since it cannot attribute the degradation); leaving the lock in place on the grounds that scope is locked, which keeps the recall numbers flattering by construction and unfalsifiable
